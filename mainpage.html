Shader System

Voxel Cone Tracing (VCT)

Global illumination technique based on scene voxelization and multi-axis cone tracing. Allows smooth indirect lighting, diffuse reflections, and dynamic light propagation in real-time.

02
Shader System

Screen Space Global Illumination (SSGI)

Real-time global illumination system based on screen space, using raymarching and temporal accumulation to simulate indirect light bounces. Developed with a focus on balancing visual quality and performance.

03
Shader System

Temporal Anti-Aliasing (TAA)

Temporal anti-aliasing shader with reprojection and accumulation between frames to smooth jagged edges and reduce noise from effects like SSGI and screen space reflections.

04
Shader System

Screen Space Ambient Occlusion (SSAO)

Screen space ambient occlusion shader that adds depth and surface contact by simulating indirect shadows in regions less exposed to light.

05
Shader System

Cinematic Lens Flare

Post-processing effect that simulates optical dispersion of real lenses, using multiple layers, ghosting, and bloom to create a dynamic cinematic aesthetic.

06
Shader System

Volumetric Lighting

Volumetric lighting shader that simulates light beams passing through particles in the environment, creating atmospheric effects like illuminated fog, god rays, and real-time cinematic depth.
